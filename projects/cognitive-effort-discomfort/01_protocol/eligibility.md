# Eligibility Criteria

## Review Type
Scoping Review (Arksey & O'Malley, 2005; JBI methodology)

---

## Inclusion Criteria

### Population
- Healthy adults (≥18 years)
- Studies may include mixed samples (healthy + clinical) IF results for healthy participants are reported separately
- No restriction on sex, ethnicity, or occupation

### Concept
Studies must address AT LEAST ONE of the following:
1. **Somatic discomfort during/after cognitive effort**: Any measure of physical discomfort, pain, headache, or bodily sensations during or following a sustained cognitive task
2. **Effort cost/aversion mechanisms**: Studies measuring why cognitive effort feels costly or aversive (effort discounting, subjective effort ratings, motivational shifts)
3. **Neural metabolic consequences of sustained cognition**: Neuroimaging or metabolic studies showing brain changes (glutamate, glucose, activation patterns) during prolonged cognitive work
4. **Interoceptive/predictive processing accounts of effort**: Studies linking cognitive effort to interoceptive signals, allostatic regulation, or predictive processing frameworks
5. **Theoretical frameworks**: Papers proposing mechanistic models connecting cognitive effort to discomfort signals (even if primarily theoretical)

### Context
- Sustained cognitive task ≥30 minutes (or equivalent sustained demand paradigm)
  - Acceptable tasks: N-back, Stroop (sustained blocks), AX-CPT, working memory tasks, sustained attention tasks, simulated workday paradigms, multi-tasking paradigms
  - Task must require effortful cognitive control (not passive viewing or simple reaction time)
- Must include a comparison point: rest, low-demand control, or pre-task baseline
- Any setting: laboratory, online/remote, simulated workplace, field study

### Study Design
- Any empirical design: RCTs, quasi-experimental, within-subjects, between-subjects, longitudinal, cross-sectional, neuroimaging, psychophysiological
- Theoretical/conceptual papers IF they propose a novel mechanistic framework directly relevant to the research question
- Systematic reviews or meta-analyses IF they synthesize evidence directly on the cognitive effort → discomfort relationship

### Date Range
- Published 2010–2026

### Language
- English only

---

## Exclusion Criteria

| Code | Criterion | Rationale |
|------|-----------|-----------|
| P1 | Exclusively clinical headache/pain population (migraine, chronic TTH) without healthy controls | Cannot speak to the healthy-population phenomenon |
| P2 | Pediatric (<18 years) or animal studies | Outside scope |
| I1 | Cognitive task <30 minutes with no sustained demand manipulation | Insufficient to induce cumulative effort effects |
| I2 | Purely pharmacological intervention without cognitive task | Not about cognitive effort |
| I3 | Physical exercise or physical fatigue only (no cognitive component) | Different mechanism |
| C1 | No comparison point (no baseline, no control, no pre-post) | Cannot attribute effects to cognitive effort |
| S1 | Case reports, editorials, letters, conference abstracts only | Insufficient detail for charting |
| S2 | Narrative reviews without novel theoretical contribution | No new evidence or framework |
| T1 | Published before 2010 | Outside date range |
| L1 | Not in English | Language restriction |
| D1 | Duplicate publication | Redundant |

---

## Screening Decision Rules

- **INCLUDE**: Clearly meets population + concept + context criteria
- **MAYBE**: Uncertain on any criterion → default to INCLUDE (liberal screening for scoping review)
- **EXCLUDE**: Clearly fails one or more exclusion criteria → record exclusion code

## Notes
- Scoping reviews are intentionally broad; when in doubt, include
- Theoretical papers are eligible if they propose novel frameworks for the effort-discomfort relationship
- Studies with mixed populations (healthy + clinical) are included if healthy subgroup data is extractable or if the framework is generalizable
