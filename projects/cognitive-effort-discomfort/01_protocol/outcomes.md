# Charting Variables (Scoping Review Outcomes)

## Note
This is a scoping review — we do not extract poolable effect sizes. Instead, we chart study characteristics and findings using the domains below.

---

## Primary Charting Domains

### 1. Somatic Discomfort Measures
- Visual Analogue Scale (VAS) for pain/discomfort/headache
- Headache rating scales
- Fatigue scales (e.g., VAS fatigue, MFI, Chalder)
- Bodily discomfort inventories
- Pericranial tenderness (algometry or self-palpation)
- Subjective symptom checklists

### 2. Effort Cost Measures
- Effort discounting tasks (indifference points)
- Subjective effort ratings (NASA-TLX, VAS effort)
- Willingness-to-exert-effort paradigms
- Decision shifts toward low-effort options
- Motivational withdrawal measures

### 3. Neural/Metabolic Markers
- fMRI (task-related activation, connectivity)
- MRS (glutamate, GABA, lactate levels)
- EEG (alpha power, theta changes, P300 amplitude)
- Pupillometry (tonic/phasic pupil dilation)
- Cerebral blood flow measures
- Glucose/glycogen proxies

### 4. Somatic Localization
- Head-specific (frontal, temporal, occipital)
- Behind eyes / periorbital
- Neck / pericranial
- General / diffuse fatigue
- Not assessed / not reported

### 5. Theoretical Framework
- L1: Effort cost (opportunity cost, effort paradox, EVC)
- L2: Neural metabolic (glutamate, glycogen, energetic)
- L3: Aversive signal (dACC, effort monitoring)
- L4: Predictive processing (interoception, allostasis, free energy)
- L5: Somatic/pain mechanisms (sensitization, pericranial)
- Multiple / integrative
- Atheoretical / descriptive only

---

## Secondary Charting Domains

### 6. Task Characteristics
- Task type (N-back, Stroop, AX-CPT, sustained attention, simulated workday, other)
- Task duration (minutes)
- Demand level manipulation (high vs. low, parametric)
- Breaks/rest periods during task

### 7. Sample Characteristics
- Sample size (N)
- Age (mean, range)
- Sex distribution
- Screening criteria used (headache screening, health screening)
- Recruitment source (university, community, online)

### 8. Study Design
- Design type (within-subjects, between-subjects, mixed, longitudinal)
- Control condition type (rest, low-demand, passive, active)
- Randomization (yes/no)
- Blinding (if applicable)

### 9. Key Findings
- 1-2 sentence summary of main finding relevant to review question
- Direction of effect (effort increased discomfort? metabolic change? decision shift?)
- Statistical significance reported (yes/no, p-value if available)
